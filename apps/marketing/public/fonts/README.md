# Font Files

Place your custom font files here:

- `CalSans-SemiBold.woff2` - Display font for headings

You can download Cal Sans from:
- https://github.com/calcom/font

Or use an alternative display font like:
- Clash Display
- Satoshi
- General Sans
- Space Grotesk

Update the font import in `app/layout.tsx` accordingly.
